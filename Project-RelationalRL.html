Lifted / Relational Reinforcement Learning

Kaushik Roy, Srijita Das, Harsha Kokel

Approximating utility functions for sequential decision making usually requires sampling huge numbers of states — a problem made worse in real domains, which tend to be both large and relational. Learning rich relational representations lets us cluster similar states together into lifted models that are far more sample-efficient.

This thread focuses on efficient relational representation learning and sequential decision making for hybrid domains, combining structured symbolic representations with deep models for interpretable utility approximators, knowledge-augmented imitation learning from multiple noisy experts, and task-specific abstractions that combine planning with RL.
