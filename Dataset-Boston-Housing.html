Dataset

Boston Housing Prices: Regression

Using regression to predict housing values in Boston suburbs.

Target

medv

Features

crim, zn, indus, nox, rm, age, tax …

Author

Navdeep Kaur

Overview

Concerns housing values in Boston suburbs, based on the Boston Housing Dataset from UC Irvine (originally from the StatLib library at Carnegie Mellon). The target, medv, is the median value of owner-occupied homes in $1000s, predicted from 13 features including crime rate, room count, and tax rate.

Setup

unzip Boston-Housing.zip
java -cp BoostSRL.jar edu.wisc.cs.will.Boosting.Regression.RunBoostedRegressionTrees -reg -l -train train/ -target medv -trees 20
java -cp BoostSRL.jar edu.wisc.cs.will.Boosting.Regression.RunBoostedRegressionTrees -i -test test/ -aucJarPath . -target medv -model train/models/ -trees 20
