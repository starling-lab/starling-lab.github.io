Communicating with Computers

Mayukh Das, Harsha Kokel, Sriraam Natarajan · DARPA CwC Program

This DARPA-funded project builds an over-arching framework for human-machine collaboration: AI agents and humans that interact seamlessly, make decisions and solve problems together, and learn from and complement each other's capabilities.

Active preference elicitation lets an agent ask for exactly the guidance it needs during planning, rather than requiring a human to fully specify preferences up front. Concept learning and teaching allow new logical concepts to be induced from a handful of human-guided examples, and domain transfer lets learned concepts extend to new but related tasks. Later work applied this to natural-language collaborative planning, culminating in the Lara system for human-guided collaborative problem solving.
