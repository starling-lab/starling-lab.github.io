MaRePReL

Nikhilesh Prabhakar, Ranveer Singh, Harsha Kokel, Sriraam Natarajan, Prasad Tadepalli · AAMAS 2025

Multiagent Reinforcement Learning (MARL) introduces several challenges to sequential decision-making: the curse of dimensionality from exponential state and action spaces, non-stationarity of the environment, and credit assignment. Add the complexity of relational domains — where policies must generalize to an increasing number of objects and tasks — and traditional MARL approaches can't learn or scale efficiently. Our work introduces MaRePReL (Multiagent Relational Planning and Reinforcement Learning), a framework that addresses these challenges by integrating hierarchical relational planning with reinforcement learning, extending our original RePReL framework to handle domains with multiple agents.

MaRePReL

MaRePReL Architecture

MaRePReL addresses the key issues in MARL as follows:

  1. Relational planner as a centralized controller. Rather than treating the problem space as a monolithic entity, MaRePReL uses a relational hierarchical planner to decompose tasks into structured sub-tasks, managing exponential state-action complexity by breaking the problem into smaller, manageable units.
  2. Handling non-stationarity through task distribution. The planner acts as a centralized controller, ensuring agents receive well-defined, non-overlapping tasks — structuring interactions to reduce the chaos of multiagent interaction and mitigate non-stationarity for more stable learning.
  3. Improving sample efficiency with abstraction reasoning. Building on RePReL, MaRePReL incorporates domain knowledge as Dynamic First-Order Conditional Influence (D-FOCI) statements to extract only the state features relevant to each agent's sub-task, reducing the samples needed for training.
  4. Enhancing generalization via task-specific lower-level policies. Once abstracted, multiple lower-level reinforcement learning policies learn to act in different tasks within the abstract state space, for different agents.

Related Work

MaRePReL with respect to existing literature on relational, hierarchical, and multiagent RL.

An ideal RL framework must handle both the rich relational structure of a domain and the decomposition of complex tasks into smaller ones — representing and reasoning with hierarchies and relational structures together. RePReL successfully handles relations and hierarchies in continuous spaces via a hierarchical relational planner and Deep RL, but can't handle multiagent systems. Given the three-pronged challenge of complex task structures, rich object-centric environments, and multiagent domains, prior work has advanced each direction separately — hierarchical RL (HRL), relational RL (RRL), and multiagent RL (MARL) — and more recently in pairwise combinations, but no significant work has encompassed all three challenges together.
