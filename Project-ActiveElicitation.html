Active Elicitation of Lab Tests

Shuo Yang, Srijita Das, Nandini Ramanan

Cheap features like demographics are available for nearly every patient; expensive ones like lab tests are not. Given some patients with the full record and many with only the cheap features, which patients should we spend the budget to test next?

We developed a unifying framework for this active feature elicitation problem and demonstrated it on four real prediction tasks — Alzheimer's, Parkinson's, postpartum depression, and rare disease identification — while also exploring human-in-the-loop elicitation and how feature acquisition should vary across subpopulations.

Paper · IJCAI 2018
