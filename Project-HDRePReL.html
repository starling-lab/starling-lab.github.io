Hybrid Deep RePReL

Harsha Kokel, Nikhilesh Prabhakar, Balaraman Ravindran, Eric Blasch, Prasad Tadepalli, Sriraam Natarajan · FUSION 2022

Our RePReL system paired a relational planner with an RL agent to accelerate learning in structured domains, but it assumed the underlying features were discrete and homogeneous — limiting it from exploiting deep RL, or from handling data arriving from multiple heterogeneous sources.

Hybrid Deep RePReL extends the architecture with two new modules: an input pre-processing module (a CNN for images, a transformer for text, or both) that produces latent embeddings for unstructured data, and a merge module that combines those embeddings with the relevant state variables from the abstraction reasoner, before handing off to the deep RL agents.
